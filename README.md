# ShareBox — NAS 实时共享聊天

跑在飞牛 NAS（fnOS）Docker 里的轻量共享服务：所有设备打开**同一个网页**，像微信群聊一样实时看到彼此发送的文本和文件，支持一键复制和下载。

## 功能

- 💬 **微信式聊天界面**：气泡对话，他人在左（白底 + 头像 + 昵称），自己在右（微信绿），文件以卡片形式发送
- 🔄 **实时同步**：所有设备打开同一网址，任何人发送的内容 2 秒内出现在大家的页面上，并显示昵称和时间
- 📝 **文本消息**：输入框粘贴文本，Enter 发送，对方点「复制」即可带走
- 📁 **文件消息**：点 📎 选择文件即发送，对方点「下载」保存（大文件流式写入，不占内存）
- 🖼️ **图片预览**：jpg / png / gif / webp / svg 等图片直接在聊天里显示，点图看大图
- 📄 **文档预览**：PDF 和文本/代码类文件（txt / md / json / csv / html / py 等）消息卡片上带「预览」按钮，点开全屏预览；其他格式（如 Office）提供下载
- 🗑️ 每条消息都可以删除
- 📱 响应式页面，手机、平板、电脑都能直接用；昵称保存在本地，重开浏览器仍在

## 部署（飞牛 NAS）

### 方式一：SSH + docker compose（推荐）

把 `sharebox` 整个文件夹上传到 NAS（如 `/vol1/1000/docker/sharebox`），然后：

```bash
cd /vol1/1000/docker/sharebox
docker compose up -d --build
```

### 方式二：飞牛 Docker 图形界面

1. 把 `sharebox` 文件夹上传到 NAS；
2. 打开飞牛的「Docker」应用 → 「Compose」→ 新建项目，选择该文件夹里的 `docker-compose.yml`；
3. 启动即可。

## 使用

1. 浏览器访问 `http://NAS的IP:8890`（手机、电脑、平板都打开这个地址）；
2. 右上角填一个昵称（如「我的手机」），每台设备填不同的，自己的消息才会靠右显示；
3. 输入文本按 Enter 发送，或点 📎 发送文件；
4. 所有已打开页面的设备在 2 秒内都会看到这条消息，点「复制」/「下载」即可；
5. 不需要的消息：**电脑**上鼠标悬停消息点「删除」（或右键 / 双击），**手机**上长按消息再点「删除」。

## 配置项（docker-compose.yml 中 environment）

| 变量 | 默认 | 说明 |
|---|---|---|
| `MAX_UPLOAD_MB` | 1024 | 单文件上传上限（MB） |

端口和数据目录在 `docker-compose.yml` 的 `ports` / `volumes` 中修改。

## 数据存储

- 所有内容存在 `./data` 目录（`sharebox.db` 元数据 + `files/` 内容），容器重建不丢失；
- 删除整个 `data` 目录即可清空所有消息。
