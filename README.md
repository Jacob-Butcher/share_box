# ShareBox — NAS 实时共享文本/文件看板

跑在飞牛 NAS（fnOS）Docker 里的轻量共享服务：所有设备打开**同一个网页**，就能实时看到彼此分享的文本和上传的文件，支持一键复制和下载。

## 功能

- 🔄 **实时共享看板**：所有设备打开同一网址，任何人分享的文本/文件会立即出现在大家的页面上（2 秒轮询同步），并显示分享者昵称、时间、大小和剩余有效期
- 📝 **文本分享**：粘贴文本 → 点「分享」→ 所有设备可见，每人点「复制」即可带走
- 📁 **文件分享**：点击/拖拽上传 → 所有设备可见，点「下载」保存（大文件流式写入，不占内存）
- ⏰ **有效期**：1 小时 / 1 天 / 7 天 / 30 天 / 永久，过期自动清理
- 🔒 **可选口令**：设置 `ACCESS_CODE` 后，分享/删除需输入口令（适合需要防误操作或公网暴露的场景）
- 🗑️ 每条分享都可以删除（设了口令则需口令）
- 📱 响应式页面，手机、平板、电脑都能直接用；昵称保存在本地，重开浏览器仍在

## 部署（飞牛 NAS）

### 方式一：SSH + docker compose（推荐）

把 `sharebox` 整个文件夹上传到 NAS（如 `/vol1/1000/docker/sharebox`），然后：

```bash
cd /vol1/1000/docker/sharebox
docker compose up -d --build
```

### 方式二：飞牛 Docker 图形界面

1. 把 `sharebox` 文件夹上传到 NAS；
2. 打开飞牛的「Docker」应用 → 「Compose」→ 新建项目，选择该文件夹里的 `docker-compose.yml`；
3. 启动即可。

## 使用

1. 浏览器访问 `http://NAS的IP:8890`（手机、电脑、平板都打开这个地址）；
2. 右上角填一个昵称（如「我的手机」），分享内容时会带上；
3. 粘贴文本或选择文件 → 选有效期 → 点「分享」；
4. 所有已打开页面的设备在 2 秒内都会看到这条内容，点「复制」/「下载」即可；
5. 不需要的内容点「删除」。

## 配置项（docker-compose.yml 中 environment）

| 变量 | 默认 | 说明 |
|---|---|---|
| `ACCESS_CODE` | 空 | 访问口令；留空则无需口令（局域网家用建议留空） |
| `MAX_UPLOAD_MB` | 1024 | 单文件上传上限（MB） |

端口和数据目录在 `docker-compose.yml` 的 `ports` / `volumes` 中修改。

## 数据存储

- 所有分享内容存在 `./data` 目录（`sharebox.db` 元数据 + `files/` 内容），容器重建不丢失；
- 删除整个 `data` 目录即可清空所有分享。
